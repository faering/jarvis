**Jarvis 1 - Captain America**: Lives on the Pi

Jarvis runs on the Pi from a CI deploy: hardened, observable, a local LLM, and a typed conversation shown on every screen.

| Component | Version | Changelog |

| app | [0.3.0](https://github.com/faering/jarvis/releases/tag/app-v0.3.0) | [CHANGELOG](https://github.com/faering/jarvis/blob/app-v0.3.0/frontend/CHANGELOG.md) |

## Added
- Per-component SSH deploy to Pi (deploy.yml) ([#37](https://github.com/faering/jarvis/issues/37))
- Model catalogue: every model per role, assigned per device, with list/pull/chat/bench tools ([#56](https://github.com/faering/jarvis/issues/56))
- Verify release artifact provenance on the Pi before installing ([#121](https://github.com/faering/jarvis/issues/121))
- Pi hardening: least-privilege deploy user, SSH, firewall, updates ([#131](https://github.com/faering/jarvis/issues/131))
- Typed conversation on the screen: keyboard input, replies shown on every presence screen ([#158](https://github.com/faering/jarvis/issues/158))
- Local LLM on the Pi: Ollama in the Pi stack with a pinned model ([#159](https://github.com/faering/jarvis/issues/159))
- Named Jarvis releases: codename, component versions and release notes per milestone ([#162](https://github.com/faering/jarvis/issues/162))
- Jarvis app on the Pi: autostart full screen, render correctly, always log ([#167](https://github.com/faering/jarvis/issues/167))
- App restarts itself after an update is installed ([#183](https://github.com/faering/jarvis/issues/183))
- Jarvis minimizes itself on request (agent->app commands) ([#219](https://github.com/faering/jarvis/issues/219))
- ADR 0013 + protocol: the agent sends the app commands ([#220](https://github.com/faering/jarvis/issues/220))
- Agent: fixed phrases ask the app to minimize (initial, until the model decides) ([#221](https://github.com/faering/jarvis/issues/221))
- App: execute window.minimize, and Ctrl+M ([#222](https://github.com/faering/jarvis/issues/222))

## Fixed
- Merging a release PR closes every issue its commits only reference ([#185](https://github.com/faering/jarvis/issues/185))
- Pi shows "Choose password for new keyring" after autologin ([#211](https://github.com/faering/jarvis/issues/211))
- Pi drops off the Wi-Fi and stays offline until rebooted ([#212](https://github.com/faering/jarvis/issues/212))
- Agent log shutdown fails when the log queue is full (flaky test on main) ([#233](https://github.com/faering/jarvis/issues/233))
